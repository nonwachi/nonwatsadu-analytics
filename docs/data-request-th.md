# ขอโครงสร้างข้อมูล Express ก่อน (ยังไม่ขอข้อมูลจริง)

สถานะ: ร่าง ยังไม่ได้ส่ง (10 พ.ย. 2569)

## วัตถุประสงค์

วิเคราะห์ผลประกอบการอย่างละเอียด ย้อนหลังหลายปี เพื่อตอบคำถามเหล่านี้

- ยอดขายเดือนต่อเดือน ปีต่อปี ช่วงไหนขึ้น ช่วงไหนลง
- สินค้า หมวด ยี่ห้อไหนทำเงิน ไหนทำกำไร
- ลูกค้าประจำ ลูกค้ารายใหญ่ แต่ละกลุ่มซื้ออะไร
- ส่วนลด คืนสินค้า ขายเชื่อ กระทบกำไรแค่ไหน
- ยอดค้างชำระและเครดิต
- จะเพิ่มยอดขายหรือปรับสต็อกตรงไหน

## ขั้นที่ 1 ขอก่อน: โครงสร้างข้อมูล (ไม่มีข้อมูลจริง)

- รายชื่อตารางทั้งหมด และฟิลด์ในแต่ละตาราง: ชื่อ ชนิดข้อมูล ความยาว คำอธิบาย
- ความสัมพันธ์ระหว่างตาราง เช่น บิลขายเชื่อมกับลูกค้าและสินค้าอย่างไร
- จำนวนแถวและช่วงวันที่ของแต่ละตาราง
- เวอร์ชัน Express และรูปแบบเก็บข้อมูล (ไฟล์หรือ SQL)
- ตัวอักษรไทยเก็บแบบไหน (TIS-620, Windows-874 หรือ Unicode) และเมื่อดึงออกมาเปิดในโปรแกรมอื่นแล้วภาษาไทยอ่านออกหรือไม่
- ตัวอย่างชื่อสินค้า 20 รายการ (ไม่ใช่ข้อมูลลูกค้า) ไว้ทดสอบภาษาไทยในโปรแกรมอื่น
- ถ้ามีคู่มือหรือเอกสารโครงสร้างข้อมูลของ Express ส่งมาด้วย
- มีสำเนาเก่าหรือแบ็กอัปของ Express ไหม เก็บไว้ที่ไหน (ใน NAS หรือที่อื่น) และย้อนไปถึงเมื่อไหร่

## ขั้นที่ 2 หลังดูโครงสร้าง

นนท์เลือกเฉพาะตารางและฟิลด์ที่ต้องใช้ แล้วขอข้อมูลจริงเฉพาะส่วนนั้น (รวมข้อมูลลูกค้าถ้าจำเป็น) เป็นสำเนาอ่านอย่างเดียว ย้อนหลังเท่าที่มี

วิธีจัดการข้อมูลที่เสนอ ให้พิจารณาตามกฎข้อ 2

- ประเภทข้อมูล: ยอดขาย ลูกค้า ต้นทุน (ข้อมูลลับ)
- ปลายทาง: คอมพิวเตอร์ของนนท์ เก็บเฉพาะในเครื่อง ไม่ขึ้น GitHub
- วิธีวิเคราะห์ ให้เลือก
  - ก. วิเคราะห์ในเครื่อง ไม่ส่งขึ้น AI บนคลาวด์
  - ข. วิเคราะห์ด้วย Claude บนคลาวด์ ต้องได้รับอนุญาตเป็นข้อ ๆ ว่าข้อมูลส่วนไหนส่งได้
- คนที่เห็นข้อมูล: นนท์ คนเดียวก่อน

## ถ้าให้ตามนี้ไม่ได้

ขอทราบว่ามีอะไรที่แชร์ได้แล้ว

- แดชบอร์ด 5 มุมมองใน NWP Hub ล่าสุด และรายชื่อว่า 5 มุมมองคืออะไร
- รายงานที่ Express ออกได้อยู่แล้ว เช่น ยอดขายตามสินค้า ตามลูกค้า ตามเดือน
- ไฟล์สรุปที่มีอยู่แล้ว
- ส่วนที่ไม่แชร์ ขอให้ระบุว่าคือส่วนไหน

## ขอยืนยัน

- ใครเป็นคนดึงข้อมูล และดึงจากสำเนาอ่านอย่างเดียวบนเครื่องอัตโนมัติ
