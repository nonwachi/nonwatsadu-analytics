# นนท์วัสดุ sales analytics

Working repo for understanding the sales performance of นนท์วัสดุ (Nonwatsadu Plus Co., Ltd.), a family building-materials shop in Mueang Lampang, Thailand.

It holds plans, data requests, query and analysis code, and findings. It does **not** hold business data. See `AGENTS.md` before adding anything.

- Start with `docs/PROJECT-PLAN.md` (goal, decisions, open items, change log).
- What data exists and how to reach it: `docs/data-landscape.md`.
- Request to the owner for data: `docs/data-request-th.md` (Thai, draft).

The website, brand and digital presence live in a separate repo: `nonwachi/nonwatsadu-website`.
